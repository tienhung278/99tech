# Issue tracker: Local Markdown

Specs and tickets live under `.scratch/<feature-slug>/`.

- Spec: `spec.md`
- Tickets: one file each under `issues/`, numbered `01-<slug>.md` onward
- Dependencies: `Blocked by:` with ticket numbers and titles
- Triage: `Status:` with the configured role name
- Comments: append under `## Comments`

Publishing creates these files; reading a ticket uses its path. A wayfinding effort uses `map.md` beside its child tickets; an unblocked, unclaimed child is the frontier.
